# DHCP Server

A simple DHCP Server which assigns IP addresses for each device automatically.

----------------------------------

# Lab setup

• 1 Server \
• 1 Switch \
• 3 PCs \
• 3 Laptops

----------------------------------

# What I did

• Configured the server Default gateway and its DNS server \
• Turned ON its DHCP service and configured its settings \
• Connected the switch to the server and also connected all the devices to the switch \
• Changed each device IPv4 settings from static to DHCP so their IPs could be automatically assigned \
• Pinged the DHCP server from each device so I know whether everything is working or not

----------------------------------

# Concepts practiced

• DHCP configuration \
• IP address assignment \
• Default gateway configuration \
• DNS Server configuration \
• Network connectivity testing
